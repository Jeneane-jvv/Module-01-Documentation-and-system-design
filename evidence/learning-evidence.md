# Skills Carried Forward

This repository is a new professional portfolio case study. It does not reproduce the wording, scenarios, answers or supplied solutions from my earlier training assessments.

The completed training work helped me build practical foundations in:

- defining a software problem and its scope;
- identifying stakeholders and documenting decisions;
- planning research and distinguishing evidence from assumptions;
- analysing data to identify patterns and needs;
- translating needs into functional, non-functional and interface requirements;
- modelling a system from more than one viewpoint;
- creating and reviewing context diagrams, use cases, DFDs, ERDs and wireframes;
- checking whether different design artefacts describe the same system;
- documenting what changed after review and debugging.

## How those skills are used here

For this portfolio project I applied those foundations to the FirstCommit concept and then reviewed the work in VS Code.

The public evidence therefore shows:

- my problem-framing process;
- my questions and design decisions;
- requirements and traceability;
- editable Mermaid design source;
- rendered design models;
- design validation;
- my VS Code review screenshots;
- my reflection on what I would improve.

## Public evidence boundary

This repository does not include:

- lecturer/provider guides;
- assessment questions or marking rubrics;
- supplied answers or model solutions;
- other students' work;
- copied application code;
- private training records;
- personal identifiers.

The repository is intended to show the engineering reasoning and design work that I can explain and defend myself.
